# 💼 DevOps from Scratch to Pro – Project Index 🔥

Welcome to the **DevOps-AWS** repository! This repo contains hands-on, real-world DevOps projects covering core tools and concepts – from Shell Scripting to Kubernetes 🚀  
Perfect for beginners, job seekers, and cloud-native enthusiasts!

---

## 📁 Project Index

### 📂 `linux-shell-bash/`

#### `project-01-aws-resource-tracker/`
🔍 Lists all AWS services using Shell Scripting & AWS CLI

#### `project-02-aws-resource-list-interactive/`
🧠 Interactive script to choose AWS region & services dynamically

---

### 📂 `ansible/`

#### `project01-ansible-configure-ec2-automation/`
🚀 Automate EC2 instance setup with ad-hoc commands & Ansible playbooks  
Tasks: Install nginx, configure SSH, system updates & more

---

### 📂 `terraform/`

#### `project-01-terraform-basics/`
🌍 Provision AWS EC2 instances using Terraform  
Includes **local backend** and **remote backend** (S3 + DynamoDB)

---

### 📂 `docker/`

#### `project-01-dockerize-nodejs-app/`
📦 Dockerize and run a full Node.js app in containers

---

### 📂 `jenkins/`

#### `project-01-jenkins-docker-integration/`
🛠️ CI/CD pipeline using Jenkins on EC2  
Docker used as build agent for streamlined automation

---

### 📂 `kubernetes/`

#### `project-01-k8s-nginx-pod/`
☸️ Deploy and manage NGINX Pod manually using YAML + `kubectl`  
Tested on **Minikube**

---

## 🔧 Tech Stack Used

- **CI/CD**: Jenkins, GitHub Actions *(WIP)*
- **IaC**: Terraform, Ansible
- **Containers**: Docker
- **Kubernetes**: Minikube, kubectl
- **Cloud**: AWS (EC2, S3, IAM, CloudWatch, Route53, etc.)
- **Scripting**: Shell, Bash, AWS CLI
